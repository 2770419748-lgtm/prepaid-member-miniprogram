# 微信审核体验入口 — 后端说明

> **状态：** 已实现。  
> **日期：** 2026-11-04（Asia/Shanghai）  
> **来由：** [上线清单](https://claude.ai/artifact/4an3CTM1yuZvYHbLTSB5xM) D。会员和员工合并成一个小程序以后，员工要用后台开过的手机号登录才进工作台，微信审核员没有这样的手机号，只能看到会员页的空卡，审核容易被打回「功能无法体验」。坤总 2026-11-04 回「开工」。小程序登录页的入口由线程「合并会员和员工小程序」做（PR #21），本文件是后端和商家后台。

## 1. 怎么用

1. 超级管理员在商家后台「门店与员工 → 小程序审核入口」点「打开 7 天」，页面显示审核账号 `shenhe` 和一个随机密码（只显示这一次，库里只存哈希）。
2. 提交微信审核时把账号密码填进「测试账号」，审核说明照页面上的模板写。
3. 审核员在小程序登录页底部点「审核体验入口」，填账号密码登录，进的是**一家单独的演示公司**：两家演示门店，审核员是两家店的店长；四位演示会员（含审核员自己）有余额和流水；一份演示权益方案和模板。工作台点「切到我的会员卡」能看会员页。
4. 审完点「关闭入口」，或者等 7 天自动关闭。关了以后登录页不再显示入口，审核员已有的登录马上失效。

## 2. 规则

- **只有超级管理员**能看、打开、延长、换密码、关闭（`/review-demo`）。演示公司里的人管不了。
- **打开 = 从现在起 7 天，并生成新密码。** 开着时再点就是延长，旧密码作废，已登录的审核员不掉线。「换一个密码」只换密码不改时间。
- **演示公司第一次打开时建好**，之后一直复用。流水只能追加，审核员在里面充值、扣款都留着，不影响真实公司。
- **正常登录永远进不了演示公司**：`OrgResolver` 不认演示公司（小程序手机号登录、网页密码登录，带不带 `orgId` 都一样），只有审核体验入口能进。所以只有一家真实公司时，加了演示公司以后也不用传 `orgId`。
- **演示公司里不发起 e签宝 签署**：`POST /sign-flows` 直接 403「审核体验里不发起真实的合同签署……」，不产生合同和费用。
- **登录方式记成 `WECHAT`**（都是小程序里的登录），所以能续期、能「切到我的会员卡」。守卫每次请求都看真实公司的入口还开没开，关了或到期就 401「审核体验已关闭」。关闭、以及关着时重新打开，都会让演示公司所有人的登录版本号加一，上一轮的登录不会跟着复活。
- **防猜密码**：连续输错 5 次锁 15 分钟（记在演示审核员身上），打开或延长时解锁。
- **操作记录**（记在真实公司名下）：`REVIEW_DEMO_OPEN` 打开审核体验入口（带截止时间、是否延长、是否刚建演示公司）、`REVIEW_DEMO_PASSWORD` 更换审核密码、`REVIEW_DEMO_CLOSE` 关闭审核体验入口、`REVIEW_DEMO_LOGIN` 审核账号登录。

## 3. 接口

| 接口 | 谁 | 说明 |
| --- | --- | --- |
| `GET /auth/review-demo` | 公开 | `{ enabled }`。小程序登录页据此显示入口；出任何问题都回 false |
| `POST /auth/review-demo/login` `{ account, password }` | 公开 | 返回和员工登录一样的结构（`accessToken`、`expiresIn`、`principalType: 'STAFF'`、`staff`、`roles`）。入口关着 403「审核体验入口没有打开」，账号或密码错 401「审核账号或密码错误」 |
| `GET /review-demo` | 超级管理员 | `{ enabled, until, account, days, demo: { stores, members } \| null }` |
| `POST /review-demo/open` | 超级管理员 | 打开或延长 7 天，返回上面的内容加 `password` |
| `POST /review-demo/password` | 超级管理员 | 开着时换密码，返回加 `password`；关着 409 |
| `POST /review-demo/close` | 超级管理员 | 关闭；已经关着 409 |

两个公开接口都可带 `orgId`（测试库里有很多家公司时用），小程序不传。

## 4. 数据库

迁移 `20261104120000_org_review_demo`，`orgs` 加三列：

- `demo_of_id`：演示公司指向真实公司（唯一，一家真实公司最多一家演示公司）。真实公司为空。
- `review_demo_until`：真实公司的入口开到什么时候。为空或已过 = 关闭。关闭时写成关闭那一刻。
- `review_demo_password_hash`：审核密码的 bcrypt 哈希，关闭时清空。

约束 `orgs_demo_has_no_review_entry`：演示公司不能指向自己，也不能再开审核入口。

演示数据见 `apps/api/src/review-demo/review-demo.seed.ts`：手机号都是虚构的（审核员 199 0000 0000，会员 139 0000 000x），只存在于演示公司。
