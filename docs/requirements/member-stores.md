# 会员端可用门店

> **状态：** 坤总 2026-10-28 确认  
> **范围：** 只记需求。这次不改代码、不合并、不部署。  
> **对齐：** [UI/UX 设计规范 v1](../design/ui-design.md)（主色 `#1677FF`，文字次色 `#64748B`）· [M1 账号与门店](../backend/m1-auth-stores.md)

公开文案使用「储值会员」「会员权益」，不写具体产品名。

## 1. 会员端不看员工

会员端不设任何查看员工的入口：页面、菜单、按钮里都不出现员工。

员工相关接口对会员角色完全关闭。会员登录后不能看员工、不能建员工、也不能改员工。

## 2. 「可用门店」入口

入口在会员首页，放在权益卡片下方。

文案固定为：**可用门店 · N家**。N 是当前这名会员能看到的可用门店数量。没有门店时 N 为 0，入口仍在。

## 3. 一店一张卡片

每家店一张卡片，卡片上有：

- 店名
- 详细地址
- 营业时间
- 距离

距离只在会员授权定位之后显示。没授权就不显示距离，也不编一个假距离，列表不按远近排。授权之后，近的排前面。

## 4. 卡片右侧两个按钮

| 按钮 | 做法 |
| --- | --- |
| 导航 | 主色 `#1677FF`。用 `wx.openLocation` 打开地图，会员可以再跳到腾讯地图、高德地图或百度地图去导航。 |
| 电话 | 用 `wx.makePhoneCall`，按一下就拨这家店的联系电话。 |

## 5. 空状态

一家可用门店都没有时，页面用灰色文字显示：

**暂无可用门店，请联系商家**

灰色用设计规范里的文字次色 `#64748B`。

## 6. 门店要补的字段

现有门店已有店名、营业状态和可选地址。按这次确认，门店再增加下面这些字段。商家在后台建店时填写。会员只能看，不能改。

| 字段 | 会员端用来做什么 |
| --- | --- |
| 经纬度 | 算距离，并用 `wx.openLocation` 打开地图 |
| 详细地址 | 卡片上的地址 |
| 联系电话 | `wx.makePhoneCall` 一键拨号 |
| 营业时间 | 卡片上的营业时间 |
