## 开工门槛

**等 M0 合入且 M2 就绪后再写业务代码。** 在此之前只维护文档，不落 `apps/*` 页面。

- M0：monorepo 骨架（`apps/member-mp`、`apps/admin-web`、`apps/api`、`apps/staff-mp` 等）
- M2：账务接口（开卡 / 充值 / 扣款 / 余额 / 明细 / 门店）
- M4：沙箱电子签，到齐后再联调签署入口与后台发起

- **实现**：由前端直接实现 M3 会员小程序 + 商家 Vue3 后台；可用云端写码改仓
- **PR**：每阶段单独开 PR
- **代码评审**：技术部
- **视觉评审**：产品设计
- **合并 / 部署**：勿自行 merge / 部署。PR 链接交开发部 → 总经理 → 坤总确认后再执行
